# FinTrack — Personal Finance Management Web Application

An app designed to help users manage their personal finances more effectively and efficiently. The app allows users to record transactions either manually or automatically by scanning receipts, and provides regular expenditure analyses. It is hoped that this app will help users keep their finances under control and avoid overspending.

# Overview & Background
Personal finance management is one of the main challenges faced by students in their daily lives. As academic demands and lifestyle expenses increase, students often find it difficult to keep track of their incoming and outgoing cash flows. Most record-keeping is still done manually or is even neglected altogether because it is considered impractical. Furthermore, communal activities such as splitting expenses with friends (group sharing) often lead to complications and potential miscalculations if carried out without adequate tools. Without an efficient system to monitor budget usage and analyse expenditure automatically, students are prone to falling into a pattern of overspending.

# Key Features
- **Interactive Financial Overview:** Visual breakdown of monthly income vs. expenses using clean donut charts and quick-glance balance cards.
- **Categorized Transaction Logging:** Friction-free recording for groceries, education, entertainment, utilities, and savings.
- **Responsive & Intuitive Interface:** Thoughtfully crafted layout ensuring smooth navigation across desktop and mobile screens.
- **Persistent Data Management:** Structured relational database using SQLite to ensure fast query responses and accurate transaction histories.

- **Backend:** Python (Routing, Transaction Business Logic, API Handlers)
